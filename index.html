沒有「台灣國語」語音怎麼辦？

朗讀使用裝置內建的語音。加入台灣國語語音的方法：
・iPad／iPhone：設定 → 輔助使用 → 朗讀內容 → 聲音 → 中文 → 選「中文（台灣）」並下載（例如「美佳」）。
・Windows：設定 → 時間與語言 → 語音 → 新增語音 → 中文（台灣）；或用 Edge 瀏覽器（內建「曉臻、曉雨、雲哲」台灣語音）。
・Chromebook／Chrome：通常內建「Google 國語（臺灣）」。
加好後重新整理頁面，再到這裡選擇語音。

純閱讀：只讀詩、走進詩裡，不出現題目。體驗探索（預設）：兩句體驗後可選擇做閱讀理解。闖關評量：兩句體驗後接著做閱讀理解。
